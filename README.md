# Hi, I'm Pritam 👋

**Full Stack Software Engineer in London.** I build B2B SaaS, financial services and IoT products with **TypeScript, Node.js/NestJS, React/Angular and Java/Spring Boot**, and I've done it for 6+ years.

- 🔐 Currently at **Cynomi**, building a cybersecurity compliance platform for MSPs. I own features end to end, from requirements with CISOs to production.
- ⚡ Event-driven backends with **Kafka**, AWS SQS/EventBridge and Prefect, on PostgreSQL and MongoDB.
- 🤖 AI-native engineering: I built agentic tooling with **Claude Code, MCP servers and reusable agent skills** that cut our requirements-to-delivery time by 50%+, with every change reviewed. I also moved our AI features from Vertex AI to the **Vercel AI SDK**.
- 🏦 Previously helped modernise a banking platform used by millions (mainframe → AWS) at LTIMindtree.
- 🎓 MSc Advanced Computer Science, Swansea University.
